********************************************************* Alien Class(Entity Class) ************************************************

import javax.persistence.Entity;
import javax.persistence.Id;
import javax.persistence.Table;

@Entity
@Table(name = "alien")  // Specifies the table name in the database
public class Alien {
    
    @Id  // Marks the primary key field
    private int aId;
    
    private String aName;
    private String color;

    // Getters and setters
    public int getaId() {
        return aId;
    }

    public void setaId(int aId) {
        this.aId = aId;
    }

    public String getaName() {
        return aName;
    }

    public void setaName(String aName) {
        this.aName = aName;
    }

    public String getColor() {
        return color;
    }

    public void setColor(String color) {
        this.color = color;
    }
}






Explaination:
The Alien class represents a table in the database, and it is annotated using JPA annotations to map it to a table.

Annotations Used:
	@Entity: This annotation marks the class as an entity (i.e., a Java class that is mapped to a database table).
	@Table(name = "alien"): This annotation specifies the name of the table in the database that this class maps to (i.e., alien table).
	@Id: This marks the primary key field. In this case, aId is the primary key for the alien table.

Fields:
	aId, aName, and color represent the columns in the alien table.
