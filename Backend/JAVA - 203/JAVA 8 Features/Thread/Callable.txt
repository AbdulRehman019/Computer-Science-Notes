
## 🧠 1. What Is `Callable`?

In Java, `Callable` is an **interface** (in `java.util.concurrent`) introduced in Java 5.
It represents a **task** that can be executed by a thread **and returns a result**.

👉 In simple words:

> Callable is just like Runnable — but it can **return a value** and **throw checked exceptions**.

---

###✳️ Definition

```java
public interface Callable<V> {
    V call() throws Exception;
}
```

Here:

* `V` → the **type of result** returned (generic type).
* `call()` → the method that contains the logic of the task.

---

### 📘 Example

```java
import java.util.concurrent.Callable;

public class SumTask implements Callable<Integer> {
    private int n;

    public SumTask(int n) {
        this.n = n;
    }

    @Override
    public Integer call() throws Exception {
        int sum = 0;
        for (int i = 1; i <= n; i++) {
            sum += i;
        }
        System.out.println(Thread.currentThread().getName() + " calculated sum: " + sum);
        return sum;
    }
}
```

This class defines a **task** that calculates the sum of numbers from 1 to `n` and returns the result.

---

## ⚙️ 2. How to Execute a Callable

You cannot pass a Callable directly to a `Thread` object.
Instead, you use an **ExecutorService** (like a thread pool) to execute it.

### Example

```java
import java.util.concurrent.*;

public class CallableExample {
    public static void main(String[] args) throws Exception {
        ExecutorService executor = Executors.newSingleThreadExecutor();

        Callable<Integer> task = new SumTask(10);
        Future<Integer> future = executor.submit(task);

        // do other work here if needed
        System.out.println("Main thread doing something else...");

        // get() waits for the result
        int result = future.get();
        System.out.println("Result: " + result);

        executor.shutdown();
    }
}
```

---

### 🧩 Flow

1. You create a Callable (`SumTask`).
2. You submit it to an ExecutorService using `submit()`.
3. `submit()` returns a `Future` object.
4. You call `future.get()` to get the result (this blocks if the task isn’t finished yet).

---

## 💡 3. What Is `Future`?

`Future` is a placeholder for a result that will be available in the future.
It’s like saying:

> “Run this task in the background — I’ll come back later to get its result.”

---

### Key Methods in `Future`

| Method          | Description                                            |
| --------------- | ------------------------------------------------------ |
| `get()`         | Waits for the task to complete and returns the result. |
| `isDone()`      | Returns true if the task is finished.                  |
| `cancel()`      | Attempts to stop the task.                             |
| `isCancelled()` | Checks if the task was cancelled.                      |

---

## 🔁 4. Difference Between `Runnable` and `Callable`

| Feature              | Runnable                       | Callable                           |
| -------------------- | ------------------------------ | ---------------------------------- |
| **Method**           | `run()`                        | `call()`                           |
| **Returns Value**    | ❌ No                           | ✅ Yes                              |
| **Throws Exception** | ❌ No (only unchecked)          | ✅ Yes (checked exceptions allowed) |
| **Use Case**         | Tasks that don’t need a result | Tasks that return a result         |
| **Submit Method**    | `execute()`                    | `submit()`                         |
| **Returns**          | void                           | `Future<V>`                        |

---

### ✅ Example Comparison

#### Runnable

```java
Runnable r = () -> System.out.println("Hello");
executor.execute(r);  // no return
```

#### Callable

```java
Callable<String> c = () -> "Hello";
Future<String> result = executor.submit(c);
System.out.println(result.get());  // prints Hello
```

## ⚙️ 5. Handling Multiple Callables (invokeAll)

You can submit **multiple Callables** at once using:

```java
List<Callable<Integer>> tasks = List.of(
    new SumTask(5),
    new SumTask(10),
    new SumTask(15)
);

ExecutorService executor = Executors.newFixedThreadPool(3);
List<Future<Integer>> results = executor.invokeAll(tasks);

for (Future<Integer> f : results) {
    System.out.println("Result: " + f.get());
}
executor.shutdown();
```

👉 `invokeAll()` submits all tasks and returns a list of Futures when all are complete.

---

## ⚠️ 6. Common Pitfalls

| Mistake                             | Why It’s a Problem                    |
| ----------------------------------- | ------------------------------------- |
| Forgetting `shutdown()`             | Threads stay alive → app never ends   |
| Calling `get()` immediately         | Blocks main thread unnecessarily      |
| Submitting long tasks to small pool | Tasks get queued → slower performance |

---

## 🧩 7. Real-Life Analogy

Imagine a **boss (main thread)** and **employees (threads in pool)**:

* The boss gives each employee a task (Callable).
* Each employee works independently and later returns a result.
* The boss collects results from everyone using their **Future** reports.

Runnable = employee does work but gives no report.
Callable = employee does work **and** submits a report (result).

---

## 🧠 8. When to Use Callable

✅ Use **Runnable** if:

* You just want to perform an action (e.g., logging, sending mail, printing).

✅ Use **Callable** if:

* You want to return a result from the background computation.
* You need to handle checked exceptions in your task.

---

### 📘 Quick Summary

| Concept             | Description                                           |
| ------------------- | ----------------------------------------------------- |
| **Callable<V>**     | A task that returns a result and may throw exceptions |
| **Future<V>**       | A placeholder for that result                         |
| **ExecutorService** | Runs Callable tasks                                   |
| **submit()**        | Submits Callable, returns Future                      |
| **get()**           | Retrieves result from Future (blocks if not done)     |
