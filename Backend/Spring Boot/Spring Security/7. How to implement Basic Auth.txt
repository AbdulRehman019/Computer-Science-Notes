How to implement Basic Auth? 

1. SecurityConfig — What MUST be inside?
	Required:
		✔ SecurityFilterChain
		✔ PasswordEncoder

	Optional (but highly recommended if you want login to work using DB users):
		✔ AuthenticationManager
		✔ DaoAuthenticationProvider

	Why?
		Because Basic Auth uses Spring Security’s AuthenticationManager to validate username/password against your database.
		If you skip this, login won't work using DB credentials.

	So YES — you should add:
	@Bean
	public AuthenticationManager authenticationManager(AuthenticationConfiguration config) throws Exception {
	    return config.getAuthenticationManager();
	}
	
	@Bean
	public DaoAuthenticationProvider authenticationProvider(UserDetailsService userDetailsService,
	                                                        PasswordEncoder encoder) {
	    DaoAuthenticationProvider provider = new DaoAuthenticationProvider();
	    provider.setUserDetailsService(userDetailsService);
	    provider.setPasswordEncoder(encoder);
	    return provider;
	}

✅ 2. AuthController — REQUIRED
	Yes.
	You need:
		/signup
		Save user
		Encode password

		/login
		Authenticate user
		Later generate JWT token

	This must be a separate controller (industry standard).

✅ 3. Do you need UserDetailsService? → YES (100%)
	If your user is stored in MongoDB, Spring Security has NO idea how to read it.

	You MUST teach it:
	@Service
	public class CustomUserDetailsService implements UserDetailsService {
	
	    private final UserRepository repo;
	
	    public CustomUserDetailsService(UserRepository repo) {
	        this.repo = repo;
	    }
	
	    @Override
	    public UserDetails loadUserByUsername(String username) {
	        User user = repo.findByUsername(username)
	                .orElseThrow(() -> new UsernameNotFoundException("User not found"));
	
	        return new org.springframework.security.core.userdetails.User(
	                user.getUsername(),
	                user.getPassword(),
	                user.getRoles().stream()
	                    .map(role -> new SimpleGrantedAuthority("ROLE_" + role.name()))
	                    .toList()
	        );
	    }
	}

❗ Without this:
	Basic Auth CANNOT authenticate users from DB
	Login will always fail

✅ 4. Anything else needed? → Minimal working list
	Here is the complete list:
	✔ Required
	1. SecurityConfig
		SecurityFilterChain
		PasswordEncoder
		AuthenticationManager
		AuthenticationProvider

	2. CustomUserDetailsService
		Reads user from DB
		Converts roles → authorities

	3. AuthController
		/signup: create user
		/login: authenticate user

	4. LoginRequest DTO

	5. User entity must have
		username
		password (encoded)
		roles

✔ Optional (but recommended for clarity)
	Role enum → convert roles to authorities

🎯 Summary (Short + Clear Answer)
Component		Required?	Why?
SecurityFilterChain	✅ Yes		To configure which endpoints are secured
PasswordEncoder		✅ Yes		To encode password for login validation
UserDetailsService	✅ Yes		Authentication MUST load user from DB
AuthenticationManager	⚠️ Yes 		(if using DB login)	Needed to authenticate login request
AuthenticationProvider	⚠️ Yes		Connects UserDetailsService + PasswordEncoder
AuthController		✅ Yes		Signup & login APIs
LoginRequest DTO	✅ Yes		Login input model

🔥 Final Answer
	To implement Basic Auth properly, you need:
		✔ SecurityConfig (FilterChain + PasswordEncoder + AuthenticationManager + Provider)
		✔ AuthController (signup + login)
		✔ UserDetailsService (loads user from DB)
		✔ DTOs + Repository

	That's it. A complete working Basic Auth system.
