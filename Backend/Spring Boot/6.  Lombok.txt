***************************************************************** Lombok *********************************************************
1. Lombok is a popular library in the Java ecosystem, often used in Spring Boot applications.
2. It aims to reduce the boilerplate code that developers have to write, such as getters, setters, constructors, and more.
3. Lombok achieves this by generating this code automatically during compilation, based on your annotations you add to your Java classes.
4. Lombok generates bytecode for methods like getters, setters, constructors, equals(), hashCode(), and toString(), as specified by the annotations used in your code.
   This generated code is added to the class files(.class).
5. The Java Compiler compiles your classes, including the generated code. This means that the generated methods become part of your compiled class files.
5. When you run your application, the generated methods are available for use, just like any other methods in your classes.
