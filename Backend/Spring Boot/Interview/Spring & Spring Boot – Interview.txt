✅ Spring & Spring Boot – Interview Answers (SDE-1)
1️⃣ What is Spring? Why do we use it?
	Answer:
	Spring is a Java framework that helps us build enterprise applications by providing features like Dependency Injection, Inversion of Control, and aspect-oriented programming.
	We use Spring to reduce boilerplate code, make applications loosely coupled, and easier to test and maintain.

2️⃣ What is Dependency Injection?
	Answer:
	Dependency Injection means objects do not create their dependencies themselves.
	Instead, Spring provides the required dependencies at runtime.
	This helps in loose coupling, better testability, and easier maintenance.

3️⃣ What problem does Dependency Injection solve?
	Answer:
	It removes tight coupling between classes.
	Without DI, changing or testing code becomes difficult because objects are tightly bound to implementations.
	
4️⃣ What is Spring Boot? How is it different from Spring?
	Answer:
	Spring Boot is built on top of Spring and simplifies application development by providing:
		Auto-configuration
		Embedded servers like Tomcat
		Starter dependencies
		Minimal configuration

	Spring requires manual configuration, whereas Spring Boot reduces setup time significantly.

5️⃣ What are @Component, @Service, and @Repository?
	Answer:
	They are stereotype annotations used to define Spring beans.
		@Component → generic bean
		@Service → business logic layer
		@Repository → data access layer and handles database exceptions

6️⃣ How does Spring create and manage beans?
	Answer:
	Spring uses an IoC container to create and manage beans.
	Beans are created at application startup and their lifecycle is managed by Spring.

7️⃣ What is ApplicationContext?
	Answer:
	ApplicationContext is the Spring container that manages beans, handles dependency injection, and provides configuration information.

8️⃣ What is @Autowired? How does Spring decide which bean to inject?
	Answer:
	@Autowired is used to inject dependencies automatically.
	Spring resolves dependency:
		By type
		If multiple beans exist → uses @Qualifier or @Primary
		If still unresolved → throws exception

9️⃣ What happens if multiple beans of the same type exist?
	Answer:
	Spring throws NoUniqueBeanDefinitionException unless:
	One bean is marked @Primary, or
	A specific bean is mentioned using @Qualifier

🔟 What are bean scopes in Spring?
	Answer:
	Common bean scopes are:
		singleton (default)
		prototype
		request
		session

	Singleton means one instance per Spring container.

1️⃣1️⃣ What is REST?
	Answer:
	REST is an architectural style for building web services that are stateless and use HTTP methods like GET, POST, PUT, and DELETE.

1️⃣2️⃣ What is @RestController?
	Answer:
	@RestController is a combination of @Controller and @ResponseBody.
	It returns data directly as JSON or XML instead of rendering a view.

1️⃣3️⃣ Difference between @RequestParam and @PathVariable
	Answer:
	@PathVariable is used to get values from the URL path
	Example: /users/{id}

	@RequestParam is used to get query parameters
	Example: /users?id=10

1️⃣4️⃣ How do you handle exceptions in Spring Boot?
	Answer:
	Exceptions can be handled using:
		@ExceptionHandler for controller-level handling
		@ControllerAdvice for global exception handling

1️⃣5️⃣ What is JPA? What is Hibernate?
	Answer:
	JPA is a specification for ORM in Java.
	Hibernate is a popular implementation of JPA.

1️⃣6️⃣ What is @Entity?
	Answer:
	@Entity marks a class as a JPA entity and maps it to a database table.

1️⃣7️⃣ What is @Id and @GeneratedValue?
	Answer:
	@Id marks the primary key
	@GeneratedValue automatically generates primary key values

1️⃣8️⃣ How does Spring Boot connect to a database?
	Answer:
	Spring Boot uses configuration in application.properties or application.yml, such as:
		Database URL
		Username and password
		JPA settings

	Spring Boot auto-configures the datasource.

1️⃣9️⃣ Difference between save() and saveAndFlush()
	Answer:
	save() stores data but may not immediately hit the database
	saveAndFlush() saves and immediately flushes changes to the database

2️⃣0️⃣ Why is Spring Boot faster to develop applications?
	Answer:
	Because it provides:
		Auto-configuration
		Embedded servers
		Starter dependencies
		Less boilerplate code
