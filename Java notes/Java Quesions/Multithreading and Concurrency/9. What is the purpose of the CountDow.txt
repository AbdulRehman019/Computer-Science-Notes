What is the purpose of the CountDownLatch class in concurrency?
CountDownLatch is a class in the java.util.concurrent package that is used to synchronize threads in Java. It provides a way for one or more threads to wait until a set of operations performed by other threads completes. The main purpose of the CountDownLatch is to ensure that certain tasks are completed before continuing with other tasks.



Key Characteristics of CountDownLatch


Count-based:
A CountDownLatch is initialized with a count (an integer), which represents the number of events or threads that must complete before the latch allows the waiting threads to proceed.


Decrementing Count:
Each time a thread completes its task, it calls the countDown() method to decrement the count.


Blocking Behavior:
The threads that call await() on the latch will be blocked until the count reaches zero. Once the count reaches zero, all waiting threads are released.


One-time Use:
Once the count reaches zero, the CountDownLatch cannot be reused. It is a one-time synchronization aid.


❓ How CountDownLatch Works


Initialization: The CountDownLatch is initialized with a count, representing the number of threads or events that must finish before the latch releases waiting threads.


Counting Down: Each participating thread that completes its task calls countDown() to reduce the count.


Waiting for Count to Reach Zero: Threads that need to wait for the completion of the tasks call await(). These threads remain blocked until the count reaches zero.


Example: Using CountDownLatch


Scenario: Waiting for Multiple Threads to Complete Before Continuing


import java.util.concurrent.CountDownLatch;
public class CountDownLatchExample {
public static void main(String args) throws InterruptedException {
// Create a CountDownLatch with 3 as the count (3 threads to finish)
CountDownLatch latch = new CountDownLatch(3);
    // Create three threads
    Thread t1 = new Thread(new Task(latch), &quot;Thread 1&quot;);
    Thread t2 = new Thread(new Task(latch), &quot;Thread 2&quot;);
    Thread t3 = new Thread(new Task(latch), &quot;Thread 3&quot;);

    // Start the threads
    t1.start();
    t2.start();
    t3.start();

    // Wait for all threads to finish
    latch.await();  // Main thread is blocked here

    System.out.println(&quot;All threads have finished, main thread is continuing.&quot;);
}

static class Task implements Runnable {
    private CountDownLatch latch;

    public Task(CountDownLatch latch) {
        this.latch = latch;
    }

    @Override
    public void run() {
        try {
            System.out.println(Thread.currentThread().getName() + &quot; is performing work.&quot;);
            Thread.sleep(1000); // Simulate some work
            System.out.println(Thread.currentThread().getName() + &quot; has completed work.&quot;);
        } catch (InterruptedException e) {
            e.printStackTrace();
        } finally {
            latch.countDown();  // Decrement the count
        }
    }
}

}


Output:

Thread 1 is performing work.
Thread 2 is performing work.
Thread 3 is performing work.
Thread 1 has completed work.
Thread 2 has completed work.
Thread 3 has completed work.
All threads have finished, main thread is continuing.


Key Points to Remember


Count-based Synchronization:
CountDownLatch is initialized with a count, representing the number of events or threads that need to complete.


Blocking Behavior:
The await() method causes the calling thread to block until the count reaches zero.


Decrementing the Count:
Each thread calls countDown() to decrement the count by one once it finishes its task.


One-time Use:
Once the count reaches zero, the latch can no longer be used. For reusable synchronization, consider using other classes like CyclicBarrier.


Use Cases for CountDownLatch


Waiting for a set of threads to complete: For example, in parallel processing or when multiple threads are working on independent tasks, and you need to wait until all threads are done before proceeding.


Starting a task after all threads are ready: You can use CountDownLatch to ensure that multiple threads are ready to proceed before the main task starts. For instance, waiting for multiple services to initialize before the application starts.


Tests that require multiple threads to complete: In concurrent testing scenarios, CountDownLatch can be used to wait for all test threads to complete their execution before moving to the next phase.


Key Methods of CountDownLatch


countDown(): Decreases the count by one. If the count reaches zero, all waiting threads are released.


await(): Blocks the calling thread until the count reaches zero. If the count is already zero, it immediately returns.


getCount(): Returns the current count value. This can be used for monitoring the remaining number of events to complete.


Key Advantages of Using CountDownLatch


Efficient Synchronization: Allows threads to wait for multiple tasks to complete efficiently without having to continuously poll or use busy waiting.


Simple API: Provides an easy-to-use interface for synchronization without requiring complex thread management or custom synchronization mechanisms.


Controlled Execution: Helps in coordinating the start or completion of tasks in parallel processing scenarios.
