1. sorted()
	Concept:
		Sorts elements (natural order by default)

	✅ Example (Ascending)
		List<Integer> result = list.stream()
		        .sorted()
		        .toList();

		👉 Input: [5,3,1]
		👉 Output: [1,3,5]

	✅ Descending (Important)
		List<Integer> result = list.stream()
		        .sorted((a, b) -> b - a)
		        .toList();

2. distinct()
	Concept:
		Removes duplicate elements

✅ Example
List<Integer> result = list.stream()
        .distinct()
        .toList();

👉 Input: [1,2,2,3]
👉 Output: [1,2,3]

🔹 3. limit(n)

Concept:
Takes first n elements

✅ Example
List<Integer> result = list.stream()
        .limit(3)
        .toList();

👉 Input: [1,2,3,4,5]
👉 Output: [1,2,3]

🔹 4. skip(n)

Concept:
Skips first n elements

✅ Example
List<Integer> result = list.stream()
        .skip(2)
        .toList();

👉 Input: [1,2,3,4]
👉 Output: [3,4]

🔹 5. collect() ⭐

Concept:
Converts stream into collection (List, Set, Map)

✅ Example
List<Integer> result = list.stream()
        .filter(n -> n % 2 == 0)
        .collect(Collectors.toList());
🔹 6. Collectors.toList()

Concept:
Collects elements into a List

✅ Example
List<String> result = list.stream()
        .map(String::toUpperCase)
        .collect(Collectors.toList());
🔹 7. Collectors.toSet()

Concept:
Collects elements into a Set (removes duplicates automatically)

✅ Example
Set<Integer> result = list.stream()
        .collect(Collectors.toSet());

👉 Input: [1,2,2,3]
👉 Output: [1,2,3]

🧠 Important Differences
distinct() vs toSet()
Feature	distinct()	toSet()
Type	Stream	Set
Order	Preserved	Not guaranteed
Use	In pipeline	Final collection
🧠 Common Combined Examples
✅ Remove duplicates + sort
List<Integer> result = list.stream()
        .distinct()
        .sorted()
        .toList();
✅ Get top 3 smallest numbers
List<Integer> result = list.stream()
        .sorted()
        .limit(3)
        .toList();
✅ Skip first 2, then take 3
List<Integer> result = list.stream()
        .skip(2)
        .limit(3)
        .toList();
✅ Unique uppercase values
Set<String> result = list.stream()
        .map(String::toUpperCase)
        .collect(Collectors.toSet());
