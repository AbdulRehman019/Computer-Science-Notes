Disjoint Set

What Is Disjoint Set (Union-Find)?
	A Disjoint Set is a data structure used to efficiently manage a collection of disjoint (non-overlapping) sets.
	It supports two primary operations:
		Find → Determine which set a particular element belongs to.
		Union → Merge two sets into one.

✅ Why Is It Useful?
	Most commonly used in Kruskal’s MST Algorithm to detect cycles.
	Also used in connected components problems and dynamic connectivity problems.

✅ Core Concepts
	1️⃣ Representation
		Each set is represented by a single representative element (parent/root).
		Example:
			Set {1, 3, 5} → Representative (root) = 1.
			
	Internally, we use:
		An array parent[] where:
		parent[i] stores the parent of element i. 

✅ There are two ways to implement Disjoint Set: 
	1. Union By Rank
	2. Union By Size

✅ Union By Rank
	Rank basically represents height of a graph(set). 
	But we are not saying height, because after path compression it won't represent height anymore. 
	
	Steps: 
		1. We find ultimate parents of both given node. 
		2. We find the ranks of both ultimate parents. 
		3. We attach the node with smaller rank to upper rank. 
		4. If rank of both nodes are equal, we can attach any ultimate parent to any other ultimate parent. 
		   The rank of ultimate parent of the one with which we are attaching is increased. 

	class DisjointSet {
	        List<Integer> parent;
	        List<Integer> rank;
	        
	        public DisjointSet(int n) {
	            parent = new ArrayList<>();
	            rank = new ArrayList<>();
	            for(int i = 0; i <= n; i++) {
	                parent.add(i);
	                rank.add(0);
	            }
	        }
	        
	        public int findUltimateParent(int node) {
        	    if(parent.get(node) == node) {
	                return node;
	            }
        	    
	            int ulp = findUltimateParent(parent.get(node));
	            parent.set(node, ulp);
	            return ulp;
	        }
	        
	        public void unionByRank(int u, int v) {
	            int pu = findUltimateParent(u);
	            int pv = findUltimateParent(v);
	            
	            if(rank.get(pu) > rank.get(pv)) {
	                parent.set(pv, pu);
	            }
	            else if(rank.get(pu) < rank.get(pv)) {
	                parent.set(pu, pv);
	            }
	            else {
	                parent.set(pv, pu);
	                rank.set(pu, rank.get(pu) + 1);
	            }
	        }
	    } 

✅ Why we are attaching smaller rank to upper rank? 
	Because if we attach upper rank to smaller rank more number of nodes need to traverse more while path compression. 

✅ Union By Size
	Here, you apply the same logic but instead of storing rank(height) you store number of nodes in the set. 
	Same logic for Union By Size. 

	Steps: 
		1. We find ultimate parents of both given node. 
		2. We find the size of both ultimate parents. 
		3. We attach the node with smaller size to upper size and increase the size of ulitmate parent of upper size. 
		4. If size of both nodes are equal, we can attach any ultimate parent to any other ultimate parent. 
		   The size of ultimate parent of the one with which we are attaching is increased. 

	public void unionBySize(int u, int v) {
            int pu = findUltimateParent(u);
            int pv = findUltimateParent(v);
            if(parent.get(pu) == parent.get(pv)) return;
            
            if(size.get(pu) > size.get(pv)) {
                parent.set(pv, pu);
                size.set(pu, size.get(pu) + size.get(pv));
            }
            else {
                parent.set(pu, pv);
                size.set(pv, size.get(pu) + size.get(pv));
            }
        }






	class DisjointSet {
	        List<Integer> parent;
	        List<Integer> rank;
	        List<Integer> size;
	        
	        public DisjointSet(int n) {
	            parent = new ArrayList<>();
	            rank = new ArrayList<>();
	            for(int i = 0; i <= n; i++) {
	                parent.add(i);
	                rank.add(0);
	                size.add(1);
	            }
	        }
        
	        public int findUltimateParent(int node) {
	            if(parent.get(node) == node) {
	                return node;
	            }
	            
	            int ulp = findUltimateParent(parent.get(node));
	            parent.set(node, ulp);
	            return ulp;
	        }
	        
	        public void unionByRank(int u, int v) {
	            int pu = findUltimateParent(u);
	            int pv = findUltimateParent(v);
	            if(parent.get(pu) == parent.get(pv)) return;
	            
	            if(rank.get(pu) > rank.get(pv)) {
        	        parent.set(pv, pu);
	            }
	            else if(rank.get(pu) < rank.get(pv)) {
	                parent.set(pu, pv);
	            }
	            else {
	                parent.set(pv, pu);
	                rank.set(pu, rank.get(pu) + 1);
	            }
	        }
	        
	        public void unionBySize(int u, int v) {
	            int pu = findUltimateParent(u);
	            int pv = findUltimateParent(v);
	            if(parent.get(pu) == parent.get(pv)) return;
	            
	            if(size.get(pu) > size.get(pv)) {
	                parent.set(pv, pu);
	                size.set(pu, size.get(pu) + size.get(pv));
	            }
	            else {
	                parent.set(pu, pv);
	                size.set(pv, size.get(pu) + size.get(pv));
	            }
	        }
	    }
