🔁 Common DSA Patterns
1. Two Pointers
	Used when dealing with sorted arrays or linked lists.
	Move two pointers from ends or same side
	Common in: pair sum, palindrome, window problems
	Examples:
		2Sum in sorted array
		Palindrome check
		Container With Most Water
		Dutch National Flag problem

2. Sliding Window
	Used to optimize brute-force subarray problems (reduce from O(n²) to O(n)).
	Fixed or dynamic window of elements
	Examples:
		Maximum sum subarray of size k
		Longest substring without repeating characters
		Minimum window substring

3. Prefix Sum / Cumulative Sum
	Used to calculate subarray sums in O(1) after O(n) preprocessing.
	Examples:
		Subarray sum equals k
		Range sum queries
		Count number of subarrays with sum divisible by k

4. Binary Search
	Used on sorted arrays or answers.
	Variants:
		Classic Binary Search
		Lower/Upper Bound
		Search on Answer Space
	Examples:
		Search in Rotated Sorted Array
		Median of Two Sorted Arrays
		Minimum Capacity to Ship Packages

5. Hashing / HashMap / Set
	Used for constant time lookups.
	Examples:
		Two Sum
		Longest Consecutive Subsequence
		Group Anagrams	
		Detect cycle in a graph (visited set)

6. Sorting
	Often used to simplify problem constraints.
	Examples:
		Merge Intervals
		Meeting Rooms
		Sort Colors (Dutch National Flag)

7. Greedy
	Make the best local choice and hope it leads to a global solution.
	Examples:
		Activity selection
		Fractional knapsack
		Jump Game
		Minimum number of platforms

8. Recursion & Backtracking
	Try all possible combinations with constraints.
	Examples:
		Subsets / Permutations
		N-Queens
		Sudoku Solver
		Rat in a Maze

9. Dynamic Programming
	Break problems into overlapping subproblems.
	Types:
		1D DP (Fibonacci, House Robber)
		2D DP (LCS, Edit Distance, DP on Grid)
		DP with Bitmasking
		Memoization or Tabulation

	Examples:
		0/1 Knapsack
		Longest Palindromic Subsequence
		Partition Equal Subset Sum
		10. Stack / Monotonic Stack
		Used in expression parsing, span problems, histogram area, etc.

	Examples:
		Next Greater Element
		Daily Temperatures
		Largest Rectangle in Histogram
		Valid Parentheses

11. Queue / Deque
	Used in BFS or sliding window optimizations.
	Examples:
		Sliding Window Maximum
		Rotten Oranges
		First Negative Number in Every Window

12. Graph Algorithms
	Used to represent and solve graph-based problems.
	Techniques:
		BFS/DFS
		Topological Sort
		Dijkstra's Algorithm
		Union-Find (Disjoint Set)
		Bellman-Ford

	Examples:
		Course Schedule
		Number of Islands
		Clone Graph
		Kruskal’s and Prim’s (MST)

13. Trie
	Used in dictionary problems or prefix matching.
	Examples:
		Word Search II
		Implement Trie
		Longest Word with All Prefixes

14. Bit Manipulation
	Used to perform optimized operations on integers.
	Examples:
		Single Number
		Subsets using bitmask		
		Power of Two
		XOR Queries

15. Heap / Priority Queue
	Used for top k elements, scheduling, or sorting with priority.
	Examples:
		Merge K Sorted Lists
		K Closest Points
		Median in Data Stream
		Top K Frequent Elements

16. Mathematics / Number Theory
	Involves GCD, Prime numbers, modular arithmetic.
	Examples:
		Sieve of Eratosthenes
		GCD/LCM problems
		Modular Exponentiation
		Palindrome Number

17. Union Find (Disjoint Set Union)
	Used in cycle detection, connected components.
	Examples:
		Number of Provinces
		Redundant Connection
		Accounts Merge

🔁 Advanced Patterns (Post-Intermediate)
	Line Sweep (e.g., meeting rooms, skyline problem)
	Segment Tree / Binary Indexed Tree (range queries, updates)
	Mo’s Algorithm (offline range queries)
	Reservoir Sampling
	Topological Sorting (Kahn’s or DFS)
	Heavy Light Decomposition (for trees)
