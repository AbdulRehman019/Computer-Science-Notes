// Patterns and Sub Categories
1. Arrays & Strings
	Subarray problems (Kadane’s, sliding window, prefix sum, two pointers)
	Subsequence problems (LIS, LCS, subsequence counting)
	Rearrangement (rotate, shuffle, rearrange elements)
	Searching (binary search variations, ternary search)
	Sorting (basic, advanced, custom sorting with comparators)
	Prefix/Suffix arrays
	Difference array / range updates
	String matching (KMP, Rabin-Karp, Z-function, prefix function)
	String hashing / rolling hash

2. Hashing & Maps
	Frequency counting
	Grouping (anagrams, word patterns)
	Hash-based prefix/suffix tricks
	Subarray with given sum
	Unique elements / distinct queries

3. Linked Lists
	Reversal problems (reverse entire / in k-groups / partial)
	Cycle detection & removal (Floyd’s algorithm)
	Intersection of two linked lists
	Merge sort on linked list
	Flatten linked list
	LRU cache (LinkedHashMap or custom doubly linked list + hashmap)

4. Stacks & Queues
	Monotonic stack/queue (next greater, sliding window max/min)
	Expression evaluation (infix → postfix, evaluate postfix)
	Histogram problems (largest rectangle, maximal rectangle)
	Balanced parentheses
	Design problems (Min stack, circular queue, deque operations)

5. Trees
	Binary tree traversals (recursive, iterative, Morris)
	Tree construction (from inorder+preorder/postorder)
	Diameter, height, balanced check
	Lowest common ancestor (binary lifting, Euler tour)
	Binary search tree (insert/delete/search, kth smallest/largest)
	Segment trees & Fenwick tree (range queries, lazy propagation)
	Trie (prefix tree)
	Heap (priority queue, heapify, heap sort, kth largest/smallest)

6. Graphs
	Traversals (BFS, DFS, bidirectional BFS)
	Shortest paths (Dijkstra, Bellman-Ford, Floyd-Warshall)
	Minimum spanning tree (Prim’s, Kruskal’s)
	Topological sorting (Kahn’s, DFS)
	Strongly connected components (Kosaraju, Tarjan)
	Bridges & articulation points
	Union-Find (disjoint set with path compression, union by rank)
	Bipartite graph (BFS/DFS, coloring)
	Max flow / min cut (Ford-Fulkerson, Edmonds-Karp, Dinic)

7. Dynamic Programming
	1D DP (climb stairs, house robber, coin change)
	2D DP (LCS, edit distance, matrix path problems)
	Knapsack family (0/1, unbounded, bounded, subset sum, partition)
	Digit DP (count numbers with certain properties)
	Bitmask DP (TSP, subsets, state compression)
	DP on trees (tree DP for paths, coloring, independent set)
	DP on grids (unique paths, cherry pickup, minimum path sum)
	Game DP (Grundy numbers, Nim, stone games)
	Probability/Expected value DP

8. Greedy Algorithms
	Interval scheduling / activity selection
	Huffman coding
	Minimum spanning tree (Kruskal, Prim can be seen as greedy)
	Fractional knapsack
	Scheduling with deadlines

9. Bit Manipulation
	Set/unset/toggle/check bit
	Subset generation using bits
	XOR tricks (missing number, unique element in array)
	Bit DP
	Fast exponentiation (binary exponentiation)

10. Mathematics & Number Theory
	Prime numbers (Sieve of Eratosthenes, segmented sieve)
	Modular arithmetic (mod inverse, Fermat’s theorem)
	GCD/LCM (Euclidean algorithm)
	Matrix exponentiation
	Combinatorics (nCr, nPr, Pascal’s triangle, DP for nCr)
	Modular exponentiation
	Chinese remainder theorem
	Fast Fourier Transform (FFT)

11. Advanced Structures
	Disjoint Set Union (DSU / Union-Find)
	Ordered set / multiset (balanced BSTs, TreeMap in Java)
	Rope / Treap / Splay trees
	Sparse table (RMQ, LCA)
	Mo’s algorithm (offline queries on arrays)

12. Geometry
	Convex hull (Graham scan, Jarvis march)
	Line sweep algorithms (interval problems, closest pair)
	Rotating calipers
	Computational geometry basics (area, orientation, intersections)

13. Specialized Categories
	Sliding window problems
	Two-pointer problems
	Backtracking (N-queens, Sudoku, word search, permutations)
	Recursion & divide & conquer
	String problems with DP + hashing
	Game theory (Grundy numbers, Nim variations)
