6. Binary Tree Maximum Path Sum
	You won't take the maximum answer as path because maximum can be left + right + curr. 
	You will take path as either left + curr or right + curr. 

	We are returning two things: 
	1. Path 
	2. Answer

	At every node: 
	1. Path will be either that node itself or that node + left path or that node + right path, whichever is maximum. 
	2. Answer will either come from left or right or leftPath + current node or rightPath + current node or leftPath + rightPath + currentNode. 
	   Or it can be node itself.
