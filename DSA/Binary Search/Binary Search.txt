3. Binary Search on Answers 
	When to think of this
		When the answer can lie in the range (1, n) or from (start, end). 
		Apply binary search on possible answers. 

	Default approach
		Give Brute Force(Linear Search). 
		Traverse on all possible answers linearly and return the answer when found. 
		Instead of traversing linearly, traverse using binary search. 

	Common variants
		Minimum of Maximum or Maximum of Minimum

	Classic mistakes
		While founding isPossible(), start from count = 1 or day = 1 instead of 0. 
		It will be easier to write logic. 

	Anchor problem
