4. Build an Interval Problem Mindmap
	Create a short mindmap or note:

Interval Problems
├── Greedy
│   ├── Sort by end
│   ├── Choose earliest finishing event
│   └── Use heap if overlapping
├── DP
│   ├── Subsequence-style: pick/not-pick
│   └── Use binary search to jump next non-overlapping
└── Gap Finding
    └── Sort intervals → scan for gaps

Mental Framework for Such Problems
	Whenever you see:
		Events, intervals, meetings: Think Greedy or DP.
		"Attend maximum"/"non-overlapping": Think Greedy + sort by end time.
		"K events", "maximize value": Think DP (states: index, k left).
		Large input ranges (1e9): Avoid arrays, use binary search or TreeMap.
		Questions with "free time" or "gap": Sort → Scan gaps between intervals.


Start With These Greedy Patterns:

	Sorting + Decision Making: e.g., Activity Selection
	Greedy for Max/Min: e.g., Minimum Coins, Gas Station
	Choosing Earliest/Largest/Smallest First: e.g., Job Sequencing, Jump Game
	Greedy with Stacks or Priority Queues: e.g., Remove K Digits, Reorganize String
