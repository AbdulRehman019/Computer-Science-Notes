***************************************** DP ***********************************************
Don't go till the end and make your logic. It will solve your problem using recursion but you won't be able to memoize it.
Do it while going. 

Instead of depending your logic on list or stack use count(int) so you can easily memoize.




********************************************* Greedy ****************************************************** 
Intervals, Meetings
You need to sort most of the time, but by start time or end time? You need to think that
Do you need to combine start and end and then sort or sorting them independently would help(Job Sequencing Problem).

Sometimes both sorting might seem to be working:
Like in(#452) sorting either by 0th index or by 1st will work.

Sometimes you may need to take wrong choices while moving forward, in that case you will need to remove it when you realize in future.

********************************************** Sliding Window Count Pattern ******************************** 
Instead of traversing everytime on both maps and checking if both contains equal elements. 
Use count. Always apply count on unique characters not number of characters. 

Pattern Recognition
This count concept is reused in:
	Minimum Window Substring
	Find All Anagrams
	Permutation in a String
	Any sliding window problem that compares frequency of elements


****************************************************** Left Rotate Array by k places **************************************************
If you see a problem that involves shifting, rotating, or rearranging an array in-place → think about reversing parts of it.
Reversal is a powerful trick to reorder arrays efficiently in-place.
It’s especially useful when you can’t use extra space.


**************************************** Matrix Problem *********************************************
Most of the matrix problems can be solved by just mapping rows and cols.
See what the matrix was initially, what the matrix is now? Try to look where the older element is now, what was it's position earlier, what it's position now
Try to find the relation between new postion and old position. Once found question solve.

Just like array, in matrix you can rotate, reverse or swap in matrix to achieve your desired result.
