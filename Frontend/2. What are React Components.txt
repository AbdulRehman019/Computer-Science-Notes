1. What are React Components? 
	A React component is just a JavaScript function that:
		returns UI (HTML-like JSX)
		represents one reusable piece of the screen

	Think of components as LEGO blocks 🧩
	You build small pieces → combine them → make a full app.

   	🖥️ Example (before React – boring HTML)
		<button>Login</button>
		<button>Login</button>
		<button>Login</button>

		If you want to change text → you edit every button 😬

	⚛️ Same thing with a React Component
		function Button() {
	 	 return <button>Login</button>;
		}

	Use it anywhere:
		<Button />
		<Button />
		<Button />

	Change it once, updates everywhere 😎

	Mental Model (VERY IMPORTANT)
		Component = Function → returns UI
		Input (props/state) → Component → UI
		No mystery. No magic.

2. Types of React Components
	1️⃣ Functional Components (modern React – YOU should use this)
		function Welcome() {
		  return <h1>Hello Abdul 👋</h1>;
		}

	or arrow style:
		const Welcome = () => {
		  return <h1>Hello Abdul 👋</h1>;
		};

	✅ Most common
	✅ Cleaner
	✅ Hooks work here

	2️⃣ Class Components (old, avoid for now)
		class Welcome extends React.Component {
		  render() {
		    return <h1>Hello</h1>;
		  }
		}

		👴 Legacy stuff — you’ll see it in old codebases only.

	🔄 Components can be nested
		function App() {
		  return (
		    <div>
		      <Header />
		      <Content />
		      <Footer />
		    </div>
		  );
		}

	Real apps look like this:
		App
		 ├── Navbar
		 ├── Sidebar
		 ├── ContactList
		 │    └── ContactCard
		 └── Footer

3. What is JSX? (simple definition)
	JSX = JavaScript + XML (HTML-like syntax)
	It lets you write HTML-looking code inside JavaScript. 

	Example:
		<h1>Hello World</h1>

	⚠️ This is NOT HTML
	⚠️ It runs inside JavaScript files

	🤯 Why JSX exists
		Without JSX, you’d write React like this 🤢:
			React.createElement(
			  "h1",
			  { className: "title" },
			  "Hello"
			);

	With JSX 😍:
		<h1>Hello World</h1>

	👉 JSX is just syntax sugar
	👉 Browser never sees JSX

	🔁 What really happens to JSX?
		This JSX:
			<h1 className="title">Hello</h1>

		Is converted by Babel into:
			React.createElement(
			  "h1",
			  { className: "title" },
			  "Hello"
			);

		So:
			JSX → JavaScript → Virtual DOM → Real DOM

4. ⚛️ JSX Rules (VERY IMPORTANT)
	1️⃣ JSX must return one parent element
	2️⃣ Use className, not class
	3️⃣ JavaScript goes inside {}
		You can put: variables, expressions, function calls, ternary conditions
	4️⃣ JSX attributes are camelCase
	5️⃣ JSX tags must be closed
	🔄 JSX inside Components
		function Welcome() {
		  return (
		    <div>
		      <h1>Hello Abdul</h1>
		      <p>Welcome to React</p>
		    </div>
		  );
		}

	JSX is just the return value of a function.

	❓ JSX looks like HTML — why can I use JS inside it?
		Because JSX is JavaScript, not HTML.

	❓ Why can’t I write if directly?
		Because JSX expects expressions, not statements.

5. How JSX fits into React flow (connecting dots)
	Component function
	  ↓
	returns JSX
	  ↓
	Babel converts JSX to JS
	  ↓
	React builds Virtual DOM
	  ↓
	Browser updates UI
